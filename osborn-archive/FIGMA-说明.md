# 基于 Figma 节点 5750:22895 的坐标修正版

Figma 链接对应网页画板 1920×1080，独立档案浮层在右侧，尺寸约 1457×1081，而非整页为 1464×1086。

本版修复：页面设计基准及右侧定位、导航图标不再强制白色滤镜、商品展示与右侧旗帜图片不强行拉伸。原交互保留。

注意：Figma 接口提供了独立原始 SVG 图标地址，但当前运行环境无法直接下载这些地址，因此图标仍采用先前你发来的 PNG。为了避免虚假的“像素级一致”承诺，本版仅声明完成了可依据 Figma 坐标核实的修改，未完成浏览器视觉验收。

运行：npm install，然后 npm run dev -- --port 5174。
